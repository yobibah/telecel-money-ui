# Telecel Money UI

Prototype React + TypeScript de l'application Telecel Money, extrait du projet Magic Patterns.

## Écrans inclus
- Connexion et vérification OTP
- Accueil et services
- Historique, compte et bilan
- Notifications et alertes
- Paramètres et assistance

## Installation
```bash
npm install
npm run dev
```

Build de production : `npm run build`.

Les transactions et validations affichées dans cette maquette sont des simulations côté interface.

Pour ouvrir directement un écran secondaire : ajoutez `?screen=alertes` ou `?screen=parametres` à l'URL.
